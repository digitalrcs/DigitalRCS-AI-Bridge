# Support

Use GitHub Issues for bug reports, setup problems, and feature requests:

https://github.com/digitalrcs/DigitalRCS-AI-Bridge/issues

When reporting model-response problems, include:

- VS Code version
- extension version
- selected model ID from `/bridge/models`
- output from the `DigitalRCS AI Bridge` output channel
- whether the response was collected from `source=stream` or `source=text`

Do not include bearer tokens, API keys, private source data, or proprietary model prompts.
